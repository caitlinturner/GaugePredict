Summary

GaugePredict is an open-source Python package for forecasting downstream gauge conditions using hybrid convolutional and recurrent neural networks. It ingests basin-wide U.S. Geological Survey (USGS) National Water Information System (NWIS) time series, automatically aligns multi-site predictors, and produces 1–30 day forecasts for discharge or water level. The package emphasizes reproducibility and explainability through SHAP-based feature selection, GPU-enabled training, and complete workflow notebooks spanning data acquisition, model training, and visualization. GaugePredict lowers the barrier for hydrologists and water managers to deploy data-driven forecasts across large watersheds.

Statement of Need

River-basin managers often require short-to-medium range forecasts (days to weeks) for operational decisions such as spillway operations, navigation planning, and flood preparedness. Many watersheds lack dense sensor coverage or consistent data quality, and existing statistical approaches struggle with nonstationary hydrologic patterns. GaugePredict addresses this gap by providing:

  • An end-to-end, documented workflow from USGS data retrieval through model training and evaluation.
  • Hybrid CNN-LSTM architectures tailored for multivariate hydrological time series.
  • Explainability via SHAP, enabling transparent site selection and model interpretation.
  • Turnkey examples and configuration for basin-scale applications (e.g., Mississippi River Basin) that can be adapted to other regions.

Software Description

Functionality

GaugePredict offers:

  • Data ingestion: Automated download of USGS NWIS daily values, alignment across multiple predictor gauges, handling of missing data, and optional ingestion of user-provided target CSVs [usgsnwis].
  • Modeling: CNN-LSTM architecture implemented in PyTorch for 1–30 day horizons, with standardized preprocessing and train/test splits [paszke2019pytorch].
  • Explainability: SHAP-based feature importance to rank predictor gauges and enable reduced, interpretable models [lundberg2017shap].
  • Visualization: Plotting utilities for training curves, forecast time series, SHAP summaries, and geospatial context.
  • Reproducibility: Configuration-driven runs, mock-import support for documentation builds, and example notebooks for full workflows.

Architecture

The package centers on GaugeDataModel, which prepares aligned predictor/target arrays, constructs sliding-window sequences, and standardizes inputs. Models are trained via a Trainer wrapper that logs metrics (R², NSE, Willmott) and saves artifacts (weights, scalers, SHAP outputs). Utilities in routines and plotting handle common I/O, geospatial boundaries, and evaluation visualizations. The codebase targets Python 3.8+ with optional GPU acceleration.

Quality Control

  • Unit tests cover core data handling and model utilities (expand as needed for end-to-end cases).
  • Example notebooks demonstrate complete runs on provided sample data.
  • Documentation (ReadTheDocs) describes installation, API usage, and troubleshooting.

Example Usage

A minimal 7-day forecast workflow:

from GaugePredict.predict import run_horizon

results = run_horizon(
    forecast_horizon=7,
    data_files="path/to/predictor/files",
    use_csv_target=False,
    target_site="07374000",
    target_parameter_code="00060",
    start_date="2020-01-01",
    end_date="2023-12-31",
    tz="UTC",
    hp={"epochs": 50, "batch_size": 32, "sequence_length": 30},
    device="cuda"  # or "cpu"
)

print(results["metrics"], results["model_path"])

Impact and Reuse

GaugePredict is suitable for:

  • Short-to-medium range discharge and water-level forecasting across large basins.
  • Sensitivity analysis of predictor networks using SHAP to identify informative gauges.
  • Rapid what-if experiments by swapping predictor sets or horizons without rewriting pipelines.
